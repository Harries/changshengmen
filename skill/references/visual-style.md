# Visual Style（视觉规范）

## 基调
国风仙侠电影质感，写实偏水墨，低饱和青灰主色调，夜景冷蓝。
长生令 / 长生门的法光用青白色与金色霞光。

## 人物
- 真实五官比例，**不要网红脸、不要长脸**；五官真实、有生活感和记忆点。
- 允许轻微黑眼圈、肤色不均、细小毛孔等真实瑕疵；妆容极淡、近素颜，**不磨皮、不美颜、无滤镜**。
- 提示词固定后缀：`真实五官比例，非网红脸，不磨皮`。
- 避免：动漫夸张表情、现代元素、画面文字（片名卡除外）。

## 摄影
电影级布光、浅景深、胶片颗粒；镜头运动缓慢克制；无人物时用空镜呼吸感。

## 统一调色（GRADE，ffmpeg）
```
scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,
setsar=1,fps=30,
eq=saturation=0.62:contrast=1.07:brightness=-0.015,
colorbalance=rs=-0.04:gs=0.02:bs=0.10:rm=0.02:bm=0.04:bh=-0.02,
noise=alls=7:allf=t,format=yuv420p
```
所有镜头（含说话特写）统一过一遍，保证全片色彩一致。

## 转场
镜头间 0.7 秒交叉叠化（xfade fade）。实现注意：xfade 会吃掉转场时长，
先用 `tpad=clone` 把每个镜头垫长 0.7s 再做 xfade 链，否则成片会被缩短。
参考：`~/workspace/changshengmen-ch01-film/work/fix_v3_video.py` 的垫长做法。

## 镜头多样性（硬要求，2026-10-04 第二章教训）
- **同一个场景/空镜，全片只用一次**（最多 2 次，且两次出现必须隔得足够远，观众察觉不到）。
- 长篇对话戏（画外音、独白、长解说）**必须**配多角度空镜 + 人物反应镜头交叉剪辑：特写（门缝/纹路/道具）、仰视/俯视变角度、人物聆听/沉思反应、环境空镜轮着用。
- **禁止**：同一个镜头在全片循环重复使用（第二章 v1 曾把同一个门循环 8 段、105 秒，被用户否决）。
- 交付前自查：逐段过一遍分镜表，确认无重复场景。

## 片头片尾
- **开头封面卡** 4 秒（用户 2026-10-03 要求）：黑底金字，内容三行——
  `长 生 门`（150px）/ 金线 / `第X卷 · <卷名>`（58px）/ `第X章 · <章名>`（58px），
  Noto Serif CJK SC Bold；淡入 0.8s、淡出 0.7s；拼在正片前（concat 滤镜重编码，
  注意 PNG 循环素材的时间戳问题，不要用 `-c copy` 直接拼）。
- 片尾卡 5 秒：`长生门 · 第X章 <章名> / 下集：<下章名>`，金字黑底。
- 标题卡用纯黑底 + 金字，避免视频模型烧字。
