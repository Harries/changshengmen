# 《长生门》人物小传（定版长相）

> 硬规则（2026-10-06 用户要求）：**各个人物长相必须全片/全系列保持一致，不能脸变了还是同一个人。**
> 每个角色有一段**固定长相描述**，凡是该角色出镜的 prompt，必须**原样引用**整段描述，一字不改。
> 新角色首次出镜前，先定版：生成后截图存 `references/faces/<角色>.jpg`，把长相描述写进本文件，后续沿用。
> 每章交付前抽查：同一角色在不同镜头的脸是否为同一张脸。

## 使用方法

生成某角色对白/出镜镜头时，prompt 结构固定为：

```
[场景]，[角色名]，[上面整段固定长相描述]，[动作/表情]，[语气]说出以下中文台词，嘴型必须与台词逐字同步，声音与画面同步，画面无任何文字：「台词」国风仙侠电影质感，写实偏水墨，低饱和青灰色调。
```

**不许**只写"十六七岁少年"这种泛称；**不许**每次换形容词；**不许**省略长相段。
