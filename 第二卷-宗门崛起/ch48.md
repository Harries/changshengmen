# 《长生门》

## 第四十八章 筑基丹

生死台一战,林砚,一战成名！

消息像长了翅膀,一天之内,传遍了整个青玄宗。外门弟子,看他的眼神,从同情、敬畏,变成了崇拜。内门弟子,提起"林砚"这个名字,也多了几分郑重。

以炼气八层,击败炼气九层巅峰,这份战绩,足以让任何人侧目。

外门,茅屋前,挤满了来道贺的弟子,黑压压,一片,把,小院,围得,水泄不通,连,站的地方,都没了。周大海忙前忙后,比自己赢了还高兴,嗓子,都喊哑了。

"兄弟,你现在可是咱们外门的传奇了！"周大海咧嘴笑道,脸,笑成了,一朵花,"我决定了,以后就跟你混了,你吃肉,我喝汤！你,指哪,我,打哪！"

"说什么呢。"林砚笑着锤了他一拳,"咱们是兄弟,有福同享！"

正说着,人群分开,苏晚晴走了进来。她一出现,四周顿时安静下来,所有人的目光,都集中在她身上。

"苏仙子！"

"恭喜林师弟,一战成名。"苏晚晴微笑道,清冷的脸上,带着真诚的喜悦,"筑基丹,可收好了？那可是无价之宝,别让人惦记了去。"

"收好了。"林砚拍拍怀里,"师姐,你找我,有事？"

"嗯。"苏晚晴正色道,"我是来跟你说筑基的事的。筑基,是修行路上第一道大坎,凶险无比,尤其是心魔劫,稍有不慎,就会走火入魔,轻则修为尽废,重则身死道消。"

她顿了顿,眼中,闪过一丝追忆:"我筑基时,也差点栽在心魔劫上。那时,我看到了小时候,爹娘逼我修炼,日夜不停,我,恨他们,恨修行。心魔,就化作他们的样子,质问我,为什么要修行。我差点,就沉沦了。最后,是师尊,一声断喝,把我,喝醒的。"

"你要记住,心魔由心生,你越怕什么,越在乎什么,它就化作什么,来,动摇你,来,诱惑你。"苏晚晴,看着林砚,一字一句道,眼神,郑重,"守住本心,问问自己,为何修行。答案,在你心里,谁也,帮不了你,只有你自己,能,渡自己！"

林砚郑重点头:"多谢师姐指点,我记下了。师姐,你为何修行？"

苏晚晴一愣,随即,笑了:"为了,守护。我要守护宗门,守护,在乎的人。你呢？"

"为了报仇,为了,守护。"林砚,毫不犹豫,"杀父之仇,不共戴天。还有,我要守护,像周大海这样的兄弟,像,师姐你这样的朋友,不再让,任何人,欺负你们！"

苏晚晴的心,微微一颤,看着他的眼睛,轻声道:"好,我等着,等你,来守护我。"

林砚郑重点头:"多谢师姐指点,我记下了。"

"还有这个。"苏晚晴取出一块玉佩,递给他,"静心玉佩,能让人保持灵台清明,渡心魔劫时,或许能帮上你。"

"这太贵重了,我不能收。"林砚推辞。护脉丹、传讯纸鹤,现在又是静心玉佩,苏晚晴帮他的,太多了。

"拿着。"苏晚晴不由分说,塞进他手里,"就当是我,提前恭贺你筑基成功。"

林砚握着玉佩,心中暖流涌动,眼眶,微微发热。这个女子,外冷内热,对他的好,他都记在心里,没齿难忘。

"师姐,你放心。"他认真道,眼神,坚定,如,磐石,"我一定筑基成功,不辜负你的期望！等我出来,咱们,一起,去内门！一起,修炼,一起,变强！"

"好。"苏晚晴,点头,眼中,满是,信任,"我,等你。"

"我相信你。"苏晚晴点点头,转身离去。走到门口,她,又停下,回头,看着林砚,欲言又止,最终,只是道:"林砚,活着出来。"

"好！"林砚,郑重点头。

望着她,离去的背影,林砚,心中,五味杂陈。这个女子,为他,做了太多。他,暗暗发誓,一定要,筑基成功,一定要,变强,强到,能,守护她！

当天晚上,钱执事也来了,带来一个好消息:长老会特许,林砚可以闭关冲击筑基,若筑基成功,可直接参加内门考核,无需参加外门大比。

"多谢钱执事！"林砚大喜。外门大比在两个月后,他若闭关一月筑基,时间,刚刚好。而且,内门考核,比外门大比,更直接,只要,通过,就能,进内门！

"好好把握。"钱执事,拍拍他的肩膀,语重心长,"老夫很看好你,别让老夫失望。记住,筑基,是,第一道,大坎,心魔劫,凶险,你,要,守住本心！"

"我记下了！"林砚,郑重点头。

送走钱执事,林砚开始准备闭关。丹药、灵石、干粮,一一备齐。遗迹得来的五百灵石,还剩不少,血牙的储物袋里,还有三千多灵石,足够他挥霍。他,将,灵石,分门别类,装好,又,将,丹药,检查了一遍,确认,无误。

"筑基,是大事,马虎不得。"他,在心里道,"丹药,灵石,都要,备足,以防万一。"

临闭关前,他去看了周大海,叮嘱他好好修炼,又给了他,一百块灵石:"兄弟,这些,你拿着,好好修炼,争取,早日筑基！"

临闭关前,他去看了周大海,叮嘱他好好修炼,又去后山,望着断魂涧的方向,轻声道:"顾前辈,爹,等我筑基成功,就离报仇,更近一步了。你们,在天上,看着我。"

"前辈……"他在心里呼唤长青子,依然没有回应。老爷爷,还在沉睡。

没有长青子护法,这次闭关,他只能靠自己。但他不怕。血牙那一战,生死台那一战,都是他靠自己,赢下来的！

第二天清晨,林砚走进外门后山的闭关石室。石室里,刻着聚灵阵,灵气浓郁,是外门弟子闭关的圣地。石室,不大,却,五脏俱全,石床,蒲团,一应俱全,墙上,还刻着,静心咒,能让人,心神宁静。

石门,缓缓关闭,将喧嚣,隔绝在外,只剩下,满室的,寂静,和,浓郁的,灵气。

林砚盘膝坐下,取出筑基丹,放在面前,又取出静心玉佩,挂在胸前,又,将,护脉丹,放在,手边,以备不时之需。

"筑基,我来了！"

他闭上眼睛,心神,沉入修炼之中。

石室外,周大海守了很久,才一步三回头地离开,嘴里,还念叨着:"兄弟,你,一定要,成功啊！"

苏晚晴站在远处的山坡上,望着石室的方向,白衣飘飘,轻声道:"林砚,等你出来。我,相信你,一定,能成功。"

山风,吹起她的衣袂,猎猎作响,她,就那么,静静地站着,站了很久,很久,直到,月上中天,才,转身离去,背影,决然,却,带着,一丝,牵挂。

闭关,开始。石室里,林砚,已,沉入修炼,对外界,的一切,浑然不觉。他的世界里,只剩下,灵力,和,道台！只剩下,那,一往无前的,决心！

石室外,周大海,带着几个,信得过的兄弟,日夜,守着,不让,任何人,打扰。他知道,兄弟的筑基,关乎,生死,关乎,未来,马虎不得！他,甚至,立下规矩,谁敢,靠近石室,打扰林砚,就,跟他,拼命！

而内门,赵无极,听到林砚闭关筑基的消息,脸色,阴沉得,能滴出水来,拳头,握得,咯咯作响,指甲,掐进肉里,鲜血,直流,却,浑然不觉,浑然不痛。他,恨得,牙痒痒,恨不得,生啖其肉,饮其血,却,无可奈何。生死台上,他,已经,输了,按祖制,不能,再寻衅。他,只能,祈祷,林砚,筑基失败,走火入魔,身死道消,永世,不得超生,打入,十八层地狱！

（第四十八章完）
